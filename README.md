# WHTZ Minecraft Server Website

## Structure

```
whtz-server/
├── index.html
├── css/
│   ├── style.css
│   └── animations.css
├── js/
│   ├── main.js
│   ├── modal.js
│   └── copy.js
└── README.md
```

## Features

- Minecraft-style pixelated UI
- Add Server modal with IP/Port copy
- Help modal with Coming Soon placeholder
- Server status bar
- Responsive design
- Keyboard accessible

## Usage

Open `index.html` in a browser. No build step required.

## Tech

HTML5 + CSS3 + JavaScript ES6+
